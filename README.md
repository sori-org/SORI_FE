SORI_FE
"소상공인의 목소리, SORI" 프로젝트의 프론트엔드 저장소입니다. SORI는 SNS 마케팅에 어려움을 겪는 소상공인들을 위해 AI 기반으로 맞춤형 마케팅 콘텐츠를 자동으로 생성해주는 웹/앱 서비스입니다.

프로젝트 소개
과거 소상공인들의 주요 홍보 수단은 전단지, 배너 등 인쇄매체 중심이었으나, 최근에는 SNS, 블로그, 온라인 광고 등 디지털 플랫폼 중심으로 빠르게 변화하고 있습니다. 이러한 변화 속에서 온라인 마케팅의 중요성은 높아지고 있지만, 많은 소상공인들은 콘텐츠 제작과 SNS 활용에 어려움을 겪고 있으며, 시간적·경제적 부담으로 인해 효과적인 온라인 마케팅 실행이 쉽지 않은 상황입니다. 특히 조사결과 대부분의 소상공인의 연령대는 50~60대로 나타났는데 이들은 SNS 사용 경험이 적고, 콘텐츠 기획·디자인 역량이 부족하여 전문가 의존도가 높고 비용 부담이 큽니다. 기존 마케팅 대행 서비스는 월 수십만 원 이상의 비용이 소요되며, 디자인 외주 역시 1건당 수만 원 이상의 단가로 소상공인이 지속적으로 이용하기에는 경제적 부담이 큽니다. 또한, 변화하는 소비자 트렌드와 SNS 알고리즘에 따라 정형화된 콘텐츠로는 소비자의 관심을 끌기 어려운 상황입니다. 따라서, 초보자도 쉽게 사용할 수 있고 , 시간과 비용을 절감할 수 있으며 , 차별화된 콘텐츠를 자동으로 생성해주는 서비스에 대한 수요가 높아지고 있습니다.





이에 따라, 본 프로젝트에서는 AI 기반 자동 콘텐츠 생성 플랫폼 "소리(SORI)"를 개발하여, 소상공인들의 마케팅 효율성을 높이고 지역 경제 활성화에 기여하고자 합니다. SORI는 '시장의 소리에 귀 기울이고, 소상공인의 목소리를 마케팅 콘텐츠로 울려 퍼지게 한다'는 의미를 담고 있습니다. 이 서비스는 사용자가 간단한 조작만으로 트위터, 인스타그램 등 소셜 미디어에 적합한 마케팅 콘텐츠를 생성할 수 있도록 돕습니다. AI를 활용해 이미지와 텍스트 형식, 네컷만화, 표지 총 3가지 형태로 결과를 제공하며 , 날씨 데이터, 리뷰 데이터, 트렌드 데이터, 지역 행사 정보 중에서 선택하여 콘텐츠에 반영함으로써 사용자 맞춤형 마케팅 자료를 효과적으로 생성할 수 있습니다. 이를 통해 정형화된 마케팅 도구와 차별화된 독창적인 콘텐츠를 제공하며, 콘텐츠 제작 시간을 단축하고 마케팅 비용을 절감하는 동시에, 도달률과 고객 참여율을 효과적으로 높일 수 있도록 지원합니다. 궁극적으로는 소상공인의 마케팅 효율성 증대와 지역 경제 활성화에 기여하는 것을 목표로 합니다.





주요 기능

마케팅 콘텐츠 자동 생성: 사용자의 간단한 선택(홍보 채널, 홍보 대상, 타겟층, 포함 정보 등)을 기반으로 AI가 자동으로 마케팅 게시물을 생성합니다.


다양한 콘텐츠 형식: 이미지와 텍스트 형식, 네컷만화, 표지 총 3가지 형태로 결과를 제공합니다.


Tip 버튼: 사용자가 쉽게 이해할 수 있도록 돕습니다. SNS 사용이 익숙하지 않은 사용자들을 위해 각 단계별로 유용한 정보를 제공하여 쉽게 기능을 이해하고 활용할 수 있도록 돕습니다.


My 페이지: 프로필 수정, 로그아웃, 가게 정보 수정, 가게 정보 등록, 가게 정보 삭제를 할 수 있습니다.


기록 보기: 그동안 생성했던 마케팅 게시물을 확인할 수 있으며, 오래된 순 또는 최신 순으로 정렬이 가능합니다.


카카오 로그인: 카카오 로그인 기능을 제공합니다.

기술 스택
본 시스템은 클라이언트-서버 아키텍처를 기반으로 구축되었습니다. 프론트엔드 애플리케이션은 사용자의 인터페이스를 담당하며, 백엔드 API 서버와 RESTful 통신을 통해 데이터를 주고받습니다. AI 모델은 백엔드에서 호출 및 관리되며, 데이터베이스에 저장된 정보를 활용하여 마케팅 콘텐츠를 생성합니다.


프론트엔드
본 프로젝트의 프론트엔드는 현대적인 웹 개발 트렌드를 반영하고 효율적인 개발 및 유지보수를 위해 다음과 같은 기술 스택을 선정하였습니다.


핵심 라이브러리: React v18.3.1 

컴포넌트 기반 개발: UI 요소를 재사용 가능한 컴포넌트로 분리하여 개발 생산성 및 유지보수성을 향상시켰습니다.

선언적 UI: 데이터 변화에 따른 UI 업데이트를 효율적으로 관리하여 복잡한 사용자 인터페이스 구현에 용이합니다.

활발한 커뮤니티: 풍부한 자료와 라이브러리 지원으로 개발 과정의 난이도를 낮췄습니다.


빌드 도구: Vite v6.0.1 

빠른 개발 서버: HMR(Hot Module Replacement)을 통한 빠른 개발 환경을 제공하여 개발 효율성을 극대화했습니다.

최적화된 빌드: Rollup 기반의 최적화된 번들링을 통해 배포용 애플리케이션의 성능을 확보했습니다.


상태 관리: Zustand v5.0.2 

경량성 및 간결성: 최소한의 API로 전역 상태를 효과적으로 관리할 수 있어 러닝 커브가 낮고 코드의 가독성이 좋습니다.

유연한 상태 구조: 다단계 폼 데이터(formData)와 UI 관련 상태(currentStepIndex) 등 복잡한 전역 상태를 효과적으로 관리하는 데 활용했습니다.


HTTP 통신: Axios v1.8.4 

Promise 기반 HTTP 클라이언트: 백엔드 API와의 비동기 통신(GET, POST 등)을 간편하게 처리하고, 인터셉터 기능을 통해 인증 토큰 관리 및 공통 에러 핸들링을 효율적으로 구현했습니다.


라우팅: React Router DOM v6.0.2 

SPA에서 페이지 전환 및 URL 관리를 담당하여 사용자가 자연스러운 내비게이션 경험을 할 수 있도록 지원합니다.


폼 관리: React Hook Form v7.55.0, @hookform/resolvers v5.0.1, Zod v3.24.2 

폼 유효성 검사 및 폼 데이터 관리를 위한 라이브러리입니다. 렌더링 최적화를 통해 복잡한 폼에서도 성능 저하 없이 효율적인 사용자 경험을 제공합니다.


react-hook-form과 유효성 검사 스키마(예: Zod)를 연동하는 데 사용되었습니다.

Zod는 런타임 유효성 검사를 위한 스키마 정의 라이브러리입니다. 강력한 타입 추론 기능을 제공하여 폼 데이터의 타입 안전성을 높이고, 백엔드 스키마와의 일관성을 유지하는 데 기여했습니다.


스타일링: styled-components v6.1.13, styled-reset v4.5.2 


styled-components는 CSS-in-JS 방식으로 컴포넌트 스코프 스타일링을 통해 스타일 충돌을 방지하고, 컴포넌트와 스타일을 함께 관리하여 유지보수성을 높였습니다.

props를 활용한 조건부 스타일링으로 유연하고 재사용 가능한 UI 컴포넌트 생성이 가능했습니다.

styled-reset은 브라우저 간 기본 스타일 불일치를 해소하여 일관된 UI 렌더링 환경을 제공합니다.


마크다운 렌더링: react-markdown v10.1.0 

백엔드에서 전달받은 마크다운 형식의 텍스트(

description)를 HTML로 변환하여 사용자에게 풍부한 시각적 콘텐츠를 제공하는 데 활용되었습니다.


데이터 페칭: @tanstack/react-query v5.74.4, @tanstack/react-query-devtools v5.74.4 

서버 상태(Server State) 관리를 위한 라이브러리입니다.

데이터 캐싱, 비동기 데이터 동기화, 로딩/에러 상태 관리 등을 자동화하여 API 데이터 페칭의 복잡성을 줄이고 사용자 경험을 향상시켰습니다.


@tanstack/react-query-devtools는 React Query 개발자 도구로, 캐싱된 데이터 확인 및 쿼리 상태 디버깅에 활용되어 개발 효율성을 높였습니다.


개발 도구: ESLint v9.15.0, MSW v2.7.4 

ESLint는 코드 품질 유지 및 스타일 가이드를 준수하기 위한 린트 도구입니다. 팀 내 코딩 컨벤션 강제 및 잠재적 오류를 사전에 방지하는 데 기여했습니다.

MSW(Mock Service Worker)는 네트워크 요청을 가로채어 API를 모킹하는 데 사용됩니다. 백엔드 개발이 완료되지 않았거나, 특정 시나리오 테스트를 위해 독립적인 프론트엔드 개발 환경을 구축하는 데 활용될 수 있습니다.
